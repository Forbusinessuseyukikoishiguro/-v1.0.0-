🐰 はじめに読んでね:なぜ「水準」を示すの?(WHY→WHAT→HOW)
WHYなぜ必要?

依頼トラブルの多くは「手抜き」ではなく「期待した品質レベルのズレ」が原因です。依頼側が水準を示さないと、受け手は毎回100点を狙って時間切れになるか、60点で出して差し戻されるか、どちらかの事故が起きます。

WHAT何をする?

依頼時に「どのレベルで仕上げてほしいか(L1〜L4)」を必ずセットで伝えます。受け手は、水準が示されていなければ確認する。それだけです。

🍜 うさうさラーメン店でいうと…
同じ一杯でも「まかない(L1)」「常連さん(L2)」「一見のお客さま(L3)」「取材の食レポ(L4)」では、盛り付けにかける時間が違いますよね。店長が「まかないでいいよ」と言ってくれれば、新人さんは安心して10分で出せます。それを言わないと、まかないに30分かけてランチタイムに間に合わない…という事故が起きるのです。
HOWどう使う?

依頼する側は「依頼カードをつくる」タブでカードを作成してチャットに貼るだけ。依頼を受けた側は「依頼を受けたら確認」タブのチェックリストで、聞き漏れがないか確認してから着手します。

「何を」だけでなく「どのレベルで」を伝えれば、依頼の事故は激減する。

0 / 6 確認済み
  • 品質水準(L1〜L4)を確認した?示されていなければ「これはL2のラフでいいですか?それともL3で仕上げますか?」と確認
  • 完成イメージ・OKラインを確認した?「何ができていれば合格か」を一文で言えるか
  • NGライン(地雷)を確認した?絶対に避けるべきことが分かっているか
  • 最終期限と中間確認のタイミングを確認した?長めのタスクは中間確認を自分から提案する
  • かける時間の目安は水準と釣り合っている?L1に3時間かけない。L4を30分で済ませない
  • 詰まったときの相談ルールを確認した?例:15分悩んだら相談。事実と所感を分けて報告

📖 品質水準 早見表(掲示用)

🍜 L1 まかない|ラフ・たたき台
  • 目的:方向性の確認。誤字・体裁くずれOK
  • 目安時間:本気版の2〜3割
  • 例:構成メモ、手書きラフ、箇条書き案
🍥 L2 常連さん|チーム内共有レベル
  • 目的:講師間レビュー・内部検討に使える
  • 体裁はおおむね整っている。細部のブレは許容
  • 例:レビュー用スライド初稿、社内向け手順メモ
🏮 L3 一見さん|受講生配布レベル
  • 目的:受講生の目に触れる。研修の品質そのもの
  • 誤字ゼロ・体裁統一・動作確認済み
  • 例:配布テキスト、演習解説、タイムテーブル
📺 L4 取材対応|顧客・社外提出レベル
  • 目的:会社の看板を背負う成果物
  • セルフチェック+第三者ダブルチェック必須
  • 例:顧客提出報告書、提案資料、公開教材

💡 運用のコツ:依頼側は 水準+理由 をセットで(「L2でOK、明日のレビューのたたき台だから」)。情報は理由とセットで共有する、が合言葉です。
